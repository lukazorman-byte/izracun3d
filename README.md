# Izračun stroškov 3D-tiska

Spletna aplikacija za izračun cene 3D-tiska (elektrika, filament, material, modeliranje, profit).
Deluje v brskalniku na telefonu (iPhone, Android) in računalniku, tudi brez interneta.

**Odpri:** https://lukazorman-byte.github.io/izracun3d/

Na telefonu: Deli → *Dodaj na začetni zaslon*.

## Posodabljanje

Izvorna koda je v mapi `izvorna-koda/`. Po spremembi `izvorna-koda/src/index.html` zaženi
`python izvorna-koda/build.py` in vsebino mape `izvorna-koda/dist/` prekopiraj v koren repozitorija.
